# 聚焦光斑光子映射渲染器（Photon-Mapping Caustic Workbench）

一个**纯 Python 标准库**实现的真实光子映射渲染器，用于在两片极近、朝向相反的
接收面（窗台正面 / 隔墙背面）上方渲染可移动透明窗棂（玻璃板 + 球形聚焦透镜）产生的
焦散（focused caustic）。不使用任何预制光斑纹理，也不依赖 numpy / 第三方包。

## 启动方式

需要 Python 3.9+，无需安装依赖。

### 1. 网页实验界面（推荐）

```bash
python3 run_server.py            # 默认 http://127.0.0.1:8000/
python3 run_server.py --port 8011
```

浏览器打开打印出的地址即可。界面上可以：

- 修改**光子预算**（1k–200k）、窗棂 X/Z 位移、核函数（Epanechnikov / 高斯 / 盒核）、
  基础半径、自适应上限半径、随机种子，然后重新追踪渲染；
- 对窗台正面与隔墙背面分别切换图层：**最终图像 / 仅焦散 / 仅直接光 / 光子分布 /
  估计器状态**（充足=绿、欠采样=橙、真暗或预算耗尽=红）；
- 查看每面的焦散积分能量、峰值辐照度、光斑质心、平均足迹（平滑尺度）、欠采样/真暗像素比例；
- 顶部卡片显示每光子权重、能量记账残差、**背面焦散泄漏量**；
- “预算收敛实验”按钮一次渲染多档 N，给出归一化能量比、峰值、足迹、欠采样比例与记账残差；
- 当欠采样比例过高或检测到背面泄漏时，状态栏会把估计器的失败标志**反馈回界面**，
  提示提高预算或放宽半径（估计器 → 控件 → 重新估计的闭环）。

### 2. 命令行实验报告（不启动界面）

```bash
python3 run_experiment_cli.py
```

打印固定半径归一化、自适应清晰度/噪声权衡、半径缩放、窗棂移动泄漏、能量守恒五组数据。

### 3. 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖核函数单位面积、估计器面积归一化、功率线性、法线相容性、薄墙泄漏隔离、
能量守恒、预算收敛稳定性、窗棂位移、真实聚焦对照共 11 项。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `caustics/vec3.py` | 三维向量运算 |
| `caustics/kernels.py` | 单位面积 2D 核函数（box / Epanechnikov / 截断高斯），含归一化常数 |
| `caustics/materials.py` | 材质、Fresnel 反射率、Snell 折射 |
| `caustics/primitives.py` | 球面 / 轴对齐盒体 / 平面的光线求交，盒体六个面各自带 surface id |
| `caustics/scene.py` | 薄墙接收面、玻璃板、球形透镜、准直光束的场景定义 |
| `caustics/photon.py` | 光子路径追踪（Fresnel 随机反射折射、权重折叠、RR）、哈希网格光子图与邻域查询 |
| `caustics/estimator.py` | 核密度辐照度估计：面积归一化、法线相容性、自适应半径、足迹与有效光子数 |
| `caustics/refine.py` | 细化器：区分“确实很暗 / 采样不足 / 充足” |
| `caustics/renderer.py` | 对正反两面正交采样，直接光与焦散分开累加，杜绝重复计数 |
| `caustics/experiments.py` | 偏差、平滑尺度、能量、收敛等度量与实验编排 |
| `caustics/webapp.py` | 标准库 `http.server` 后端，`/api/render`、`/api/convergence` |
| `web/index.html` | 单页界面（原生 JS + Canvas，零依赖） |

## 关键正确性设计

1. **面积归一化**。辐照度估计为
   `E(x) = (1/R²) Σ_p Φ_p K(|x−x_p|/R)`，其中 K 是单位面积 2D 密度
   （`2π∫₀¹ K(u)u du = 1`，测试中数值验证）。因此固定半径下平均能量与光子数无关，
   增加光子只会降低方差，**不会让图片变亮**。每光子功率 = 光束总功率 / N，与发射数量匹配。
2. **真实光路**。光线在玻璃表面按 Fresnel 反射率随机选择反射/折射（Snell 定律，含全反射），
   功率按 F 或 1−F 折叠，逐事件能量守恒；漫反射按 albedo 折叠并以俄罗斯轮盘终止。
3. **薄墙不泄漏**。墙的正面 `wall.front`（外法线 +y）与背面 `wall.back`（外法线 −y）
   是独立的光子图网格；查询只取同一 surface id 的光子，并要求
   `dot(−photon.direction, normal) > 0.5` 的入射相容性，背面因此不会借到正面的焦散。
4. **直接光 / 焦散分离**。首次漫反射命中存入 direct 图，经历过镜面事件后的漫反射命中
   存入 caustic 图，渲染时每像素各加一次，避免普通照明与光子估计重复计数。
5. **暗 vs 欠采样**。估计器返回每个查询点的足迹 R 与有效光子数 n_eff；细化器在足迹已到
   上限且邻域仍无能量时判为“真暗”，否则判为“欠采样”，并对预算耗尽（n_eff≈0）单独标记。
6. **半径权衡**。缩小 R 提高焦斑清晰度（峰值升高）但稀疏区域噪声/欠采样上升；
   自适应模式按目标有效光子数（默认 8）逐步放大 R 直至上限，按局部光子密度选择估计尺度，
   通量保持不变（同一核函数、同一 1/R² 归一化）。
7. **能量闭环**。每个发射光子的最终命运记为吸收 / 逃逸 / 达到反弹上限仍存活，
   玻璃事件未跟随的另一分支也计入吸收，记账残差数值上约为 1e-14。
